# 🎟️ Seat Reservation System.

    This is my first full-stack project. The idea of the project is to make a system of seat reservation for a cinema.
    This project uses the following technologies:
        - Frontend: React, TailwindCSS, and TypeScript.
        - Backend: Node.js with Express and MongoDB.


## How to use

    1. Clone this project.
    2. Install all dependencies.
    3. Start a MongoDB instance on port :27017, with a database named `App` and a collection named `Seats`.
    4. Copy `Seed.json` and import it into MongoDB.
    5. Run the client with the command `npm run dev` inside the `.../client` directory.
    6. Run the server with the command `npx ts-node index.ts` inside the `.../server` directory.
    


## 🪑 How It Works

    1 - Select the gray seats displayed on the interface.
    2 - When one or more seats are selected, press the button below the seats labeled `Continuar` to continue with the reserve.
    3 - A form will appear on the screen, this form has three inputs, name, last name, and email.
    4 - At the bottom of the form, there are two buttons: `Cancelar` to go back and `Siguiente` to continue reserving the seats.
